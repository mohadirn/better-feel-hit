# better-feel-hit
i made a better feel hit with some technique
In this project, i take a basic hit and turn it into something much more satisfying using a bunch of simple game feel techniques.

i've add:
• Hit force and enemy reaction
• Hit color feedback
• Blood particles
• A more responsive health bar
• Camera impact shake
• Background impact effects
• And a small bug fix along the way

Everything is built from scratch in Godot, and most of these techniques can be adapted to almost any game.
